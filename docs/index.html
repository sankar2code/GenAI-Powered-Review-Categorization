GenAI-Powered Review Categorization System

Turn a pile of customer reviews into action — in one pass, in under 30 seconds.

FreshTake is a workflow tool for restaurant managers. Paste or upload a batch of reviews, and a Microsoft-Copilot-driven engineered prompt returns a structured table — sentiment, aspect tags, priority, a suggested action, and a ready-to-edit first reply — for every review, in one pass. Managers stay in the loop: every reply is reviewed, edited if needed, and approved by a human before it's sent. High-priority issues route straight into an action queue so nothing slips through.

The five flows (PRD §3.3)

This is the prototype's skeleton — click through any flow start to finish.

Flow 1 · Story 1

Review batch processing

Paste or upload a batch → submit to the engineered prompt → processing state → structured 5-column table → export to CSV/Excel.

1. New batch 2. Processing 3. Results table

Flow 2 · Story 2

Priority-based action routing

Filter by Priority = High → assign the suggested action to a department → log it with a timestamp → track Open / In Progress / Resolved.

1. Filter results 2. Action queue

Flow 3 · FR9

First reply drafting & sending

Open a review → read the AI-drafted reply → edit/personalise → human approves and sends. There is no automated send — ever.

1. Review detail & reply editor

Flow 4 · P1 · FR10

Prompt iteration & improvement

Weekly review of miscategorised cases → versioned prompt change log → accuracy tracked against the 20% manual-audit baseline.

1. Prompt library & audit

Flow 5 · P2 / V2 · §3.6

Trend monitoring

Monthly aggregation of % positive / negative / neutral, most-tagged aspects, and an alert when negative reviews cross 30% of the month's volume.

1. Trend report
